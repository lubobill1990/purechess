# 互动教程（M3c）

`levels.json` 是独立编写的 19 关零基础教程；无第三方题库或文案。
按王、后、车、象、马、兵、吃子、将军、吃将、挡将、逃将、将杀、
两道一步杀、易位、升变、吃过路兵、逼和陷阱、毕业局排序。

- `version: 1`；`fen` 是学员首次行棋的局面，`line` 是 UCI 主线。
  非毕业关由 core `PuzzleProblem` 校验并使用 `PuzzleSession` 判定，
  保留合法错着不改盘、失败后重试、自动对方应着及提示语义。
- 每关有 `intro`、`success`、`failure`；`guided` 显示起点方框和目标圆圈。
  讲解/反馈区固定 156 逻辑像素，长文可滚动，不推动棋盘。
- `goal` 是回归测试的教学事实契约。走法关另有 `piece`；应将关的
  `evasions` 给出同一局面真实存在的吃/挡/逃三法；`setupFen` +
  `setupLine` 证明过路兵确实刚走双步；`trap` 必须产生逼和。
- `tutorial_progress` 是 SharedPreferences 整数，表示已完成的连续关卡数，
  0 表示只解锁第一关，19 表示毕业。只能完成当前解锁关或重温旧关，
  旧关不降低进度；写入失败保留棋盘，显示重新保存按钮，不提前解锁。
- 毕业局不是伪装成题目的固定主线：白方对最低档 AI，黑方让后，
  正常终局或走棋后确认认输都可毕业，胜负不作门槛。应用使用 core 的
  将杀/逼和/不足子力终局，并自动裁定三次重复和 50 步和棋。
  AI 服务失败时显示明确提示，切换仅选合法着的 `FakeEngine`；
  教程实例独立管理 AI 生命周期，不影响普通对局。
- 遥测复用白名单 `puzzle_result`、`game_start/end`，毕业局 mode 为
  `tutorial`，不发送 FEN、着法或自由文案；错误走现有本地日志/错误上报。

## 并行集成

首页未改动；入口命名路由 `/tutorial`。只额外修改 `pubspec.yaml` 注册资产，
以及添加 `test/features/tutorial/` 的资产、状态与 UI 回归测试。

毕业 CTA 使用 `/puzzle/daily`。本分支没有 M3b 战术题模块，因此 router
暂时映射到教程内的入门练习页（两道原创一步杀按本地日期轮换一道，
页面明确说明不是完整每日题库）。维护者合并 M3b 时将该路由 builder
替换为完整每日题页；如采用其他路径，同步修改 `tutorialDailyRoute`。
不需修改教程进度或关卡数据。首页学习入口由 M3d 接线。

## 回归入口

```powershell
$env:NO_PROXY='localhost,127.0.0.1'
flutter test test\features\tutorial
flutter analyze
flutter test
```

资产测试逐关重放每步并断言教学事实，额外测试特殊规则反例；
状态测试覆盖线性解锁、失败重试、持久化故障、毕业与 AI 异步生命周期；
组件测试覆盖导航、讲解区尺寸、升变选择与小屏/横屏布局。
